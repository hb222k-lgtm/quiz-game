📌 Safari로 여는 방법

  1. 화면 오른쪽 하단 ··· 버튼 탭
  2. Safari로 열기 선택
  3. Safari에서 하단 공유 □↑ 탭
  4. 홈 화면에 추가 선택 → 추가 ✅

📌 직접 여는 방법

  1. 오른쪽 상단 ··· 버튼 탭
  2. 다른 브라우저로 열기 선택
  3. Chrome이 열리면 주소창 옆 ⋮ 탭
  4. 홈 화면에 추가 선택 ✅
